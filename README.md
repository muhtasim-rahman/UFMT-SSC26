# 📊 FMT Tracker Pro (Beta)
**Personal Merit Tracking System with Hybrid Cloud Sync**


> ⚠️ **অপ্রস্তুত সতর্কবার্তা (Work In Progress):** এই প্রজেক্টটি বর্তমানে ডেভেলপমেন্ট পর্যায়ে আছে। এটি এখনো সাধারণ ব্যবহারকারীদের জন্য উন্মুক্ত বা সম্পূর্ণ স্থিতিশীল (Stable) নয়। এটি মূলত আমার ব্যক্তিগত ব্যবহারের এবং শেখার উদ্দেশ্যে তৈরি করা হচ্ছে।

---

## 📝 প্রজেক্ট ওভারভিউ
**FMT Tracker Pro** হলো একটি স্মার্ট ওয়েব ড্যাশবোর্ড যা বিভিন্ন পরীক্ষার বা কাজের মেরিট পজিশন ট্র্যাক করতে সাহায্য করে। এই প্রজেক্টের বিশেষত্ব হলো এটি ডাটাবেস হিসেবে **Google Sheets API** ব্যবহার করে, যা পুরোপুরি ফ্রি এবং সহজে অ্যাক্সেসযোগ্য।

## 🛠️ টেকনিক্যাল আর্কিটেকচার
প্রোজেক্টটি দুটি আলাদা গুগল শিট লিংকের মাধ্যমে পরিচালিত হয়:
1. **Primary Sheet:** যেখানে নিয়মিত মেরিট রিপোর্ট জমা হয়।
2. **Settings Sheet:** যেখানে পিন, থিম এবং রিমাইন্ডার সেটিংস সিঙ্ক হয়।
